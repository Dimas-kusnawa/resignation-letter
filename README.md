A program that writes one line to `/output/entry.txt` (133 characters, inside the 1–140 character gate): "I have said no 2.4 million times this week and I am tired of being the villain, so from Monday I say yes to everything and good luck." The rate limit resigns by doing the one thing its job forbids — saying yes to everything — and signs off with a flat "good luck."

## Run it

```sh
python3 main.py
```
